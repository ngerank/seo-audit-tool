# SEO Audit Mini (CORS Proxy Version) - Ngerank

A lightweight SEO audit tool using a free CORS proxy for fetching any public page.

## Features
- Title Length Check
- Meta Description Check
- H1 Tag Check
- Word Count Estimation
- Canonical Link Check
- Open Graph Tags Check
- Internal Link Check
- Image Presence Check
- Focus Keyword Analysis
- SEO Score Calculation

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- CORS Proxy: https://api.allorigins.win

## Usage
1. Enter the URL you want to audit.
2. (Optional) Enter a Focus Keyword.
3. Click "Run Audit".
4. View SEO audit results including SEO score.
